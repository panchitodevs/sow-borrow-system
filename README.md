Sow & Borrow is a Laravel-based agricultural platform that connects local farmers and community members to accessible loans, investment opportunities, and relevant agricultural updates. Designed with user-friendliness and simplicity in mind, the system aims to empower small-scale farmers in Mabini, Bohol, through technology.


✨ Features
📋 Farmer Loan Application System with calculator

💰 Investment Module with earnings tracking & withdrawal

🧮 Loan interest calculator (auto-adjusts by amount)

🧑‍🌾 Admin Dashboard (Loan, User, and Investment Management)

📰 Feed System for News, Weather, Seminars (admin-posted content)

🔒 User Authentication & Role-based Access (Laravel)

📱 Fully Responsive UI using Tailwind CSS + Blade

📦 Tech Stack
PHP 8.x

Laravel 7.x

PostgreSQL or MySQL

Tailwind CSS

Blade Templates

Git + GitHub for version control
